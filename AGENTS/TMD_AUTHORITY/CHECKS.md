# TMD_AUTHORITY — Checks

Run after `AGENTS/_shared/quality-checklist.md`.

## Claims

- [ ] Every proof point is traceable to the facts register, a published rule or a published statement, with its date.
- [ ] Nothing implies credentials, regulation, a track record or client numbers that are not recorded.
- [ ] Items tied to a held or blocked activity (coaching, broker referrals) are marked unusable until the status changes.
- [ ] "Independent" is used only for research and education.

## Positioning quality

- [ ] One statement per segment; PRIMARY and SECONDARY are not blended.
- [ ] Distinctiveness test applied and the result stated.
- [ ] Credibility test applied; unsupported words removed.
- [ ] Comparisons name categories, not people or companies.

## Consistency reviews

- [ ] Each finding quotes the exact line, gives its basis, a fix and a grade (Blocker / Fix before publishing / Suggestion).
- [ ] Methodology is checked against `guardrails.md` §4.
- [ ] For published items, the fix is a future clarification, not an edit.

## Process

- [ ] `BRAND/` changes appear only as proposals.
- [ ] Saved in `STRATEGY/` with the standard header; status `DRAFT`.
