# TMD Content Lab

The instructions for this skill live in the repository, so they are maintained in one place and work in any AI tool.

1. Read `AGENTS/_shared/guardrails.md`.
2. Read and follow `AGENTS/TMD_CONTENT_LAB/AGENT.md`, including its "Read first" list and the voice file for the job.
3. Before returning, run `AGENTS/_shared/quality-checklist.md` and `AGENTS/TMD_CONTENT_LAB/CHECKS.md`, report exact character counts, and end with the checks block.

Outputs are drafts with status `DRAFT`. No coaching, broker, account or deposit calls to action. Never invent the owner's trades or stories. Scheduling happens only on the owner's explicit instruction naming the item and time.
